# Software Empire — STEP 10 Frontend

Frontend application for the Software Empire platform.

Software Empire is a software discovery and management platform that allows users to explore software, view software details, compare products, submit reviews, and manage their account. The system also provides an admin interface for managing platform data and users.

## Features

### Public Platform
- Landing Page
- Software Directory
- Software Search and Filtering
- Software Detail
- Software Comparison
- Software Recommendation
- Implementation Request
- Learn and Article Content

### Account Platform
- User Account
- Saved Software
- Software Comparisons
- Implementation Requests
- Account Settings

### Admin Platform
- Dashboard
- User Management
- Roles & Permissions
- Software Management
- Categories
- Features
- Integrations
- Vendors
- Industries
- Business Sizes
- Reviews
- Partners
- Articles
- Implementation Leads
- Admin Leads
- Analytics
- Audit Logs
- Settings

## Technology

- React.js
- Vite
- JavaScript / JSX
- CSS
- REST API
- Laravel Backend
- PostgreSQL Database
